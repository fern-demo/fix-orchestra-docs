## Message structure

<StickyTable>

| Tag | Name | Type | Presence | Description |
|---|---|---|---|---|
| | [StandardHeader](/fix/components/standard-header) | Component | **Required** | The standard FIX message header |
| 1393 | [MarketReqID](/fix/fields/tags-1200-1399#tag-1393-marketreqid) | String | **Required** | Must be unique, or the ID of previous Market Segment Request to disable if SubscriptionRequestType = Disable previous Snapshot + Updates Request(2). |
| 263 | [SubscriptionRequestType](/fix/fields/tags-200-399#tag-263-subscriptionrequesttype) | SubscriptionRequestTypeCodeSet | **Required** | Subscription Request Type |
| 1301 | [MarketID](/fix/fields/tags-1200-1399#tag-1301-marketid) | Exchange | Optional | Conditionally required if MarketSegmentID(1300) is specified on the request |
| 1300 | [MarketSegmentID](/fix/fields/tags-1200-1399#tag-1300-marketsegmentid) | String | Optional | Identifies the market segment |
| 1325 | [ParentMktSegmID](/fix/fields/tags-1200-1399#tag-1325-parentmktsegmid) | String | Optional | Specifies that the Market Segment is a sub segment of the Market Segment defined in this field. |
| | [StandardTrailer](/fix/components/standard-trailer) | Component | **Required** | The standard FIX message trailer |

</StickyTable>
