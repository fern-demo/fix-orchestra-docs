Repeating group · NumInGroup 2734 · Added FIX.5.0SP2
</llms-only>

For MiFID II RTS 2 Annex IV Table 2 reference data - all months when the roll is expected as established by the CDS index provider for a given year - repeated for each month in the roll.

Each repetition starts with the first member listed. The count of repetitions is sent in [NoIndexRollMonths (2734)](/fix/fields/tags-2600-2799#tag-2734-noindexrollmonths).
