<Badge intent="note">Repeating group</Badge> <Badge intent="info" minimal>NumInGroup 1461</Badge> <Badge intent="success" minimal>Added FIX.5.0SP1</Badge>

Each repetition starts with the first member listed. The count of repetitions is sent in [NoTargetPartyIDs (1461)](/fix/fields/tags-1400-1599#tag-1461).

## Members

<StickyTable>

| Tag | Name | Type | Presence | Description |
|---|---|---|---|---|
| 1462 | [TargetPartyID](/fix/fields/tags-1400-1599#tag-1462) | String | Optional | Required if NoTargetPartyIDs(1461) &gt; 0. Used to identify the party targeted for the action specified in the message. |
| 1463 | [TargetPartyIDSource](/fix/fields/tags-1400-1599#tag-1463) | PartyIDSourceCodeSet | Optional | Used to identify source of target party identifier. |
| 1464 | [TargetPartyRole](/fix/fields/tags-1400-1599#tag-1464) | PartyRoleCodeSet | Optional | Used to identify the role of source party identifier. |
| 1818 | [TargetPartyRoleQualifier](/fix/fields/tags-1800-1999#tag-1818) | PartyDetailRoleQualifierCodeSet | Optional | Used to further qualify the role of the target party role. |
| 2433 | [TargetPtysSubGrp](/fix/groups/target-ptys-sub-grp) | Repeating group | Optional | Repeating group of target party sub-identifiers. |

</StickyTable>
