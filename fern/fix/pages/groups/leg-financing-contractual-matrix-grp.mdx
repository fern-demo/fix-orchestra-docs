<Badge intent="note">Repeating group</Badge> <Badge intent="info" minimal>NumInGroup 42203</Badge> <Badge intent="success" minimal>Added FIX.5.0SP2</Badge>

Each repetition starts with the first member listed. The count of repetitions is sent in [NoLegContractualMatrices (42203)](/fix/fields/tags-42200-42399#tag-42203).

## Members

<StickyTable>

| Tag | Name | Type | Presence | Description |
|---|---|---|---|---|
| 42204 | [LegContractualMatrixSource](/fix/fields/tags-42200-42399#tag-42204) | String | Optional | Required if NoLegContractualMatrices(42203) &gt; 0. |
| 42205 | [LegContractualMatrixDate](/fix/fields/tags-42200-42399#tag-42205) | LocalMktDate | Optional | Specifies the publication date of the applicable version of the contract matrix. If not specified, the ISDA Standard Terms Supplement defines rules for which version of the matrix is applicable. |
| 42206 | [LegContractualMatrixTerm](/fix/fields/tags-42200-42399#tag-42206) | String | Optional | Specifies the applicable key into the relevent contract matrix. In the case of 2000 ISDA Definitions Settlement Matrix for Early Termination and Swaptions, the LegContractualMatrixTerm(42206) is not applicable and is to be omitted. See http://www.fpml.org/coding-scheme/credit-matrix-transaction-type… |
