Relative valuation metrics or analytics are commonly provided by the trading party providing pricing as part of fixed income cash bonds or OTC derivatives indication or quoting activities.

Each repetition starts with the first member listed. The count of repetitions is sent in [NoRelativeValues (2529)](/fix/fields/tags-2400-2599#tag-2529-norelativevalues).

## Members

<StickyTable>

| Tag | Name | Type | Presence | Description |
|---|---|---|---|---|
| 2530 | [RelativeValueType](/fix/fields/tags-2400-2599#tag-2530-relativevaluetype) | RelativeValueTypeCodeSet | Optional | Required if NoRelativeValues(2529) &gt; 0. |
| 2531 | [RelativeValue](/fix/fields/tags-2400-2599#tag-2531-relativevalue) | float | Optional | Required if NoRelativeValues(2529) &gt; 0. |
| 2532 | [RelativeValueSide](/fix/fields/tags-2400-2599#tag-2532-relativevalueside) | RelativeValueSideCodeSet | Optional | Specifies the side of the relative value. |

</StickyTable>
