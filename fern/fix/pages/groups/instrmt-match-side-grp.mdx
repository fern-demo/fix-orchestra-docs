<Badge intent="note">Repeating group</Badge> <Badge intent="info" minimal>NumInGroup 1889</Badge> <Badge intent="success" minimal>Added FIX.5.0SP2</Badge>

Each trade match report can contain any number of trades for any number of instruments. This component contains all instruments together with all of the trade sides (possibly more than two) that occurred for each instrument within the same match event.

Each repetition starts with the first member listed. The count of repetitions is sent in [NoInstrmtMatchSides (1889)](/fix/fields/tags-1800-1999#tag-1889).
