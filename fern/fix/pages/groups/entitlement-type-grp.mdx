When used in the PartyEntitlementRequest(35=CU) message it serves to provide filtering criteria for the results set.

Each repetition starts with the first member listed. The count of repetitions is sent in [NoEntitlementTypes (2345)](/fix/fields/tags-2200-2399#tag-2345-noentitlementtypes).

| Tag | Name | Type | Presence | Description |

| 2402 | [EntitlementSubType](/fix/fields/tags-2400-2599#tag-2402-entitlementsubtype) | EntitlementSubTypeCodeSet | Optional | Subtype of an entitlement specified in EntitlementType(1775). |
