---
title: "ReturnRateGrp"
subtitle: "ReturnRateGrp is a repeating subcomponent within the PaymentStreamFloatingRate component. It is used to specify the multiple return rates for an equity return swap payment stream."
---

<Badge intent="note">Repeating group</Badge> <Badge intent="info" minimal>NumInGroup 42735</Badge> <Badge intent="success" minimal>Added FIX.5.0SP2</Badge>

Each repetition starts with the first member listed. The count of repetitions is sent in [NoReturnRates (42735)](/fix/fields/tags-42600-42799#tag-42735).
