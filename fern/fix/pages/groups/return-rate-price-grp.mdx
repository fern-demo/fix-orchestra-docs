Repeating group · NumInGroup 42765 · Added FIX.5.0SP2
</llms-only>

Each repetition starts with the first member listed. The count of repetitions is sent in [NoReturnRatePrices (42765)](/fix/fields/tags-42600-42799#tag-42765-noreturnrateprices).

## Members

<StickyTable>

| Tag | Name | Type | Presence | Description |
|---|---|---|---|---|
| 42766 | [ReturnRatePriceBasis](/fix/fields/tags-42600-42799#tag-42766-returnratepricebasis) | ReturnRatePriceBasisCodeSet | Optional | Required if NoReturnRatePrices(42765) &gt; 0. |
| 42767 | [ReturnRatePrice](/fix/fields/tags-42600-42799#tag-42767-returnrateprice) | Price | Optional | Specifies the price of the underlying swap asset. |
| 42768 | [ReturnRatePriceCurrency](/fix/fields/tags-42600-42799#tag-42768-returnratepricecurrency) | Currency | Optional | Specifies the currency of the price of the underlying swap asset. Uses ISO 4217 currency codes. |
| 42769 | [ReturnRatePriceType](/fix/fields/tags-42600-42799#tag-42769-returnratepricetype) | ReturnRatePriceTypeCodeSet | Optional | Specifies whether the ReturnRatePrice(42767) is expressed in absolute or relative terms. |
