In the context of MiFID II, ESMA RTS 23 Annex I Table 3 reference data this component is used to convey the UTC date-times tracking the admission and expiration of a security for trading.

Each repetition starts with the first member listed. The count of repetitions is sent in [NoReferenceDataDates (2746)](/fix/fields/tags-2600-2799#tag-2746-noreferencedatadates).

## Members

| Tag | Name | Type | Presence | Description |
|---|---|---|---|---|
| 2747 | [ReferenceDataDate](/fix/fields/tags-2600-2799#tag-2747-referencedatadate) | UTCTimestamp | Optional | Required if NoReferenceDataDates(2746) &gt; 0. |
| 2748 | [ReferenceDataDateType](/fix/fields/tags-2600-2799#tag-2748-referencedatadatetype) | ReferenceDataDateTypeCodeSet | Optional | Reference data entry's date-time type. |
