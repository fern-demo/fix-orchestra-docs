Repeating group · NumInGroup 539 · Added FIX.4.3

Each repetition starts with the first member listed. The count of repetitions is sent in [NoNestedPartyIDs (539)](/fix/fields/tags-400-599#tag-539-nonestedpartyids).

## Members

<StickyTable>

| Tag | Name | Type | Presence | Description |
|---|---|---|---|---|
| 524 | [NestedPartyID](/fix/fields/tags-400-599#tag-524-nestedpartyid) | String | Optional | Used to identify source of NestedPartyID. Required if NestedPartyIDSource is specified. Required if NoNestedPartyIDs &gt; 0. |
| 525 | [NestedPartyIDSource](/fix/fields/tags-400-599#tag-525-nestedpartyidsource) | PartyIDSourceCodeSet | Optional | Used to identify class source of NestedPartyID value (e.g. BIC). Required if NestedPartyID is specified. Required if NoNestedPartyIDs &gt; 0. |
| 538 | [NestedPartyRole](/fix/fields/tags-400-599#tag-538-nestedpartyrole) | PartyRoleCodeSet | Optional | Identifies the type of NestedPartyID (e.g. Executing Broker). Required if NoNestedPartyIDs &gt; 0. |
| 2384 | [NestedPartyRoleQualifier](/fix/fields/tags-2200-2399#tag-2384-nestedpartyrolequalifier) | PartyDetailRoleQualifierCodeSet | Optional | Used to further qualify the value of NestedPartyRole(538). |
