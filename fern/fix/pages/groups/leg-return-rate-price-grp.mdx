---
title: "LegReturnRatePriceGrp"
subtitle: "LegReturnRatePriceGrp is a repeating subcomponent within the LegReturnRateGrp component. It is used to specify the return rate prices for an equity return swap payment stream."
---

<Badge intent="note">Repeating group</Badge> <Badge intent="info" minimal>NumInGroup 42564</Badge> <Badge intent="success" minimal>Added FIX.5.0SP2</Badge>

Each repetition starts with the first member listed. The count of repetitions is sent in [NoLegReturnRatePrices (42564)](/fix/fields/tags-42400-42599#tag-42564).

| Tag | Name | Type | Presence | Description |
