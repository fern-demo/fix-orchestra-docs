Repeating group · NumInGroup 40230 · Added FIX.5.0SP2
</llms-only>

Each repetition starts with the first member listed. The count of repetitions is sent in [NoPaymentSettls (40230)](/fix/fields/tags-40200-40399#tag-40230-nopaymentsettls).

## Members

<StickyTable>

| Tag | Name | Type | Presence | Description |
|---|---|---|---|---|
| 40231 | [PaymentSettlAmount](/fix/fields/tags-40200-40399#tag-40231-paymentsettlamount) | Amt | Optional | Required if NoPaymentSettls(40230) &gt; 0. |
| 40232 | [PaymentSettlCurrency](/fix/fields/tags-40200-40399#tag-40232-paymentsettlcurrency) | Currency | Optional | Specifies the currency the PaymentSettlAmount(40231) is denominated in. Uses ISO 4217 currency codes. |
| 40233 | [PaymentSettlParties](/fix/groups/payment-settl-parties) | Repeating group | Optional | PaymentSettlParties is a repeating subcomponent of the PaymentSettlGrp component used to report payment settlement routing. |

</StickyTable>
