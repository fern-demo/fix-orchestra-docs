subtitle: "UnderlyingReturnRatePriceGrp is a repeating subcomponent within the UnderlyingReturnRateGrp component. It is used to specify the return rate prices for an equity return swap payment stream."
---

<Badge intent="note">Repeating group</Badge> <Badge intent="info" minimal>NumInGroup 43064</Badge> <Badge intent="success" minimal>Added FIX.5.0SP2</Badge>

Each repetition starts with the first member listed. The count of repetitions is sent in [NoUnderlyingReturnRatePrices (43064)](/fix/fields/tags-43000-43199#tag-43064).
